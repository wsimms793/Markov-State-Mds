Toy Example of a Markov State model for a Drunkards walk, i.e., a random walk on a 2D grid.

Walk_Sim.py first to generate trajectory data and anayltical results for the invariant distrubution.

Then run MSM.py to get a MSM estimate for the invariant distrubution.

Results then talks through what this code is doing and the results of our estimation.
